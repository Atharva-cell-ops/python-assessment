# Python Basics – Programming Assessment

This folder contains solutions to the **Python Fundamentals Programming Assessment**.

---

## 📁 Files

- `question1_even_odd.py` - Checks if an integer is even or odd
- `question2_largest.py` - Finds the largest among three numbers
- `question3_sum.py` - Calculates the sum of numbers from 1 to N
- `question4_vowels.py` - Counts vowels in a string
- `question5_reverse.py` - Reverses an input string
- `question6_calculator.py` - Function-based calculator (+, -, *, /)

---

## 🚀 How to Run

```bash
python question1_even_odd.py
python question2_largest.py
python question3_sum.py
python question4_vowels.py
python question5_reverse.py
python question6_calculator.py
```
